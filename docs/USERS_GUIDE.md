# 利用者ガイド

AgentTasktrayViewerは、CodexとClaude Codeの使用量をWindowsのタスクトレイに表示する常駐アプリです。

## インストール後の起動

インストール後はスタートメニューから「AgentTasktrayViewer」を起動してください。起動すると設定画面が開き、タスクトレイには使用量アイコンが表示されます。設定画面を閉じてもアプリは常駐し、もう一度起動すると既存の設定画面が開きます。タスクトレイの「^」を開くと、隠れているアイコンを確認できます。

KotorinToysに収録した開発版は、本体の「起動 / 設定を開く」「停止させる」で操作できます。未パッケージ版では単体の「Windows起動時に開始」は利用できません。自動起動はKotorinToys側で管理し、別のMSIX版の予約と二重に有効にしないでください。

初期状態ではWindows起動時の自動起動はOFFです。自動起動を有効にする場合は、タスクトレイアイコンを右クリックして「Windows起動時に開始」をONにしてください。

## 基本操作

タスクトレイアイコンを右クリックすると、使用量の確認や、表示するアイコンの切り替えができます。更新間隔、自動起動、Claude Code連携もこのメニューから操作できます。

「表示するアイコン」のサブメニューを開いたまま、複数のアイコンを続けて切り替えられます。メニューを閉じるには、メニューの外をクリックするかEscキーを押します。

「アイコンスタイル」では輪郭線のない色付きの背景に白い文字を表示する「背景色版」と、透明な背景にサービスの色で文字を表示する「文字色版（背景なし）」を選べます。背景色版でも、使用量の警告が出るときだけは従来どおり橙色または赤色の警告枠を表示します。文字色版の文字には暗いタスクバーでも読めるよう細い明るい色の縁が付いています。初期設定は文字色版です。どちらも残量の数字は32×32ピクセルの範囲に収まる最大のサイズに自動で調整されます。

「アイコンフォント」ではこのPCにインストールされている候補から `Segoe UI`、`Arial`、`Arial Narrow`、`Bahnschrift` を選べます。スタイルとフォントは選ぶとすぐに反映され、保存されるため、トレイ上で読みやすさを比較できます。「設定...」から開く設定画面でも同じ項目を変更できます。

起動直後に使用量を確認し、表示を更新します。表示中のアイコンに対応するCodexまたはClaude Codeが見つからない場合は、タスクトレイの通知と「接続状態」メニューで状態が分かり、公式の導入案内も開けます。利用者が両方の枠を非表示にしたサービスは確認せず、警告も表示しません。

初回起動時にCLIが見つからないサービスの使用量アイコンは、既定で非表示になります。CLIが見つからないことを知らせる警告は表示されます。4つすべての使用量アイコンが非表示の場合は「AgentTasktrayViewer 設定」アイコンが表示され、クリックすると設定画面を開けます。
