# 利用者ガイド

AgentTasktrayViewerは、CodexとClaude Codeの使用量をWindowsのタスクトレイに表示する常駐アプリです。

## インストール後の起動

インストール後は、スタートメニューから「AgentTasktrayViewer」を起動してください。設定画面が開き、タスクトレイに使用量アイコンを表示します。設定画面を閉じても常駐を続けます。もう一度起動すると既存の設定画面を開きます。タスクトレイの「^」を開くと、隠れているアイコンを確認できます。

KotorinToysに収録した開発版は、本体の「起動 / 設定を開く」「停止させる」で操作できます。未パッケージ版では単体の「Windows起動時に開始」は利用できません。自動起動はKotorinToys側で管理し、別のMSIX版の予約と二重に有効にしないでください。

初期状態ではWindows起動時の自動起動はOFFです。自動起動を有効にする場合は、タスクトレイアイコンを右クリックして「Windows起動時に開始」をONにしてください。

## 基本操作

タスクトレイアイコンを右クリックすると、使用量の確認、表示するアイコンの切り替え、更新間隔、自動起動、Claude Code連携を操作できます。

「表示するアイコン」は、サブメニューを開いたまま複数のアイコンを続けて切り替えられます。メニューの外をクリックするか、Escキーで閉じます。

「アイコンスタイル」では、輪郭線なしの色付き背景へ白文字を描く「背景色版」と、背景を透明にしてサービス色の文字を描く「文字色版（背景なし）」を選べます。背景色版も使用量警告時だけは従来どおり橙色または赤色の警告枠を表示します。文字色版には暗いタスクバーでも読めるよう細い明色の縁を付けています。初期設定は文字色版です。どちらも残量の数字が32×32ピクセルの範囲へ収まる最大サイズになるよう自動調整します。

「アイコンフォント」では、このPCにインストールされている候補から `Segoe UI`、`Arial`、`Arial Narrow`、`Bahnschrift` を選べます。スタイルとフォントは選択直後に反映・保存されるため、トレイ上で読みやすさを比較できます。「設定...」から開く設定画面でも同じ項目を変更できます。

起動直後は使用量を確認して更新します。表示中のアイコンに対応するCodexまたはClaude Codeが見つからない場合は、タスクトレイ通知と「接続状態」メニューで状態を知らせ、公式の導入案内を開けます。利用者が両方の枠を非表示にしたサービスは確認対象外となり、警告も表示しません。

初回起動時にCLIが見つからないサービスは、そのサービスの使用量アイコンを既定で非表示にします。未検出の警告は表示し、4つすべての使用量アイコンが非表示の場合は「AgentTasktrayViewer 設定」アイコンを表示します。このアイコンをクリックすると設定画面を開けます。
