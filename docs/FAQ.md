# FAQ

## インストールしたのに画面が表示されません

このアプリは通常のウィンドウを表示せず、タスクトレイに常駐します。インストール後、スタートメニューから「AgentTasktrayViewer」を起動してください。タスクトレイの「^」の中にアイコンが隠れている場合があります。

## Windows起動時に自動で開始されますか？

初期状態では自動起動しません。タスクトレイの右クリックメニューにある「Windows起動時に開始」をONにすると、次回のWindows起動時から開始します。

## 現在利用できますか？

Windows 10/11 x64向けの開発中バージョンです。

## 使わないサービスの警告を止められますか？

「表示するアイコン」で、そのサービスの5時間枠と週間枠を両方とも非表示にしてください。両方の枠を非表示にしたサービスは起動時のCLI検出と警告の対象外になります。

## 4つのアイコンをすべて非表示にした場合はどうなりますか？

使用量アイコンの代わりに「AgentTasktrayViewer 設定」アイコンがタスクトレイに表示されます。アイコンをクリックすると表示設定画面を開けます。
